# Spellcraft (Fabric 1.20.1, Java 17)

Wand with 9 spells. Craft: amethyst shard + 2 sticks (diagonal), or find it in the Tools creative tab.
Right click = cast. Sneak + right click = next spell.

Build on GitHub: upload this folder to a repo -> Actions tab -> "build" -> download artifact "spellcraft-mod".
Put the jar into .minecraft/mods together with Fabric API 0.92.2 for 1.20.1.
